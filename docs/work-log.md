## 2026-06-16 — Shared canonical nav (nav.js)

**Scope**: Site-wide nav refactor per docs/NAV_REFACTOR_PLAN.md. Root cause: every app page hand-rolled its own `<nav>` (10+ drifted tab sets); `toggle.js` (agronomist view + hamburger) was live on only 4/87 pages, so the toggle was dead almost everywhere.
**Fix**: New self-contained `frontend/nav.js` renders the dashboard (index.html) canonical nav on every app page. Replaces any existing `<nav>` client-side (or inserts as first body child on nav-less pages), sets `.active` on the matching tab (logo excluded), and owns the agronomist toggle (localStorage `cultivos_view_mode`) + mobile hamburger (folded in from toggle.js). Loads BEFORE i18n.js so i18n localizes the rendered labels + wires the ES/EN toggle; the toggle button carries no `data-i18n` (mode-dependent label) and nav.js re-applies it post-i18n to avoid a clobber race.
**Rollout**: Added `<script src="/nav.js"></script>` before i18n.js on 82 pages. Excluded: login, demo, walkthrough (auth/public) + field, impacto-agricultor (farmer-minimal, founder decision). Removed superseded `toggle.js` include from index/knowledge/notifications; kept toggle.js + its include on field.html only (still needs its `.agronomo-only` toggle, no canonical nav).
**Founder decision (2026-06-16)**: canonical nav puts `#agronomo-toggle` on analytical pages too — supersedes old F8 "absent on analytical" rule. Updated the 3 F8 assertions (now expect present).
**Verification**: jsdom render harness during build (replace + insert + active + mode both ways), then full North Star gate `./scripts/verify.sh` — **5679 passed, 3 skipped, pages live E2E**. Playwright F8 (rendered, real browser) confirms toggle present + modes + persistence across pages.
**Files**: frontend/nav.js (new), tests/test_nav_shared.py (new, 5 guard tests), tests/test_f8_agronomo_toggle.py (updated), 82 frontend/*.html (added nav.js include; index/knowledge/notifications also dropped toggle.js include).
**Note**: client-render approach leaves the old per-page `<nav>` markup in raw HTML as a no-JS fallback (and to avoid breaking ~53 server-side nav-content tests). nav.js rewrites it on load.
